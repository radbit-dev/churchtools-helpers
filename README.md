These are a bunch of scripts as I work a lot with ChurchTools and have, over the time, created a few to do various things to make life easier or compensate for currently missing features.
Don't get me wrong ChurchTools is a great platform, but it cant solve all problems at once ;).

Have fun using / copying / changing.

## Available helpers

* **Open Service Reminder**: [ct-events-reminder](ct-events-reminder/)\
    Automatically scans upcoming ChurchTools events for unfilled services and sends reminder emails to **all members**, not just the leaders, in the responsible service groups.
